# ☃️ Snowman Meltdown

A simple word-guessing game written in Python. Try to guess the secret word one letter at a time before your snowman melts!

## Features

* Randomly selects a secret word.
* Accepts one letter per guess.
* Validates user input and prevents repeated guesses.
* Displays the word as letters are guessed.
* Shows the snowman's melting stages using ASCII art.
* Allows the player to play multiple rounds.

## Requirements

* Python 3
* A terminal, such as the VS Code terminal

## How to Play

1. Clone or download this repository.

2. Open the project folder in VS Code.

3. Open the terminal in the project folder.

4. Run the game:

   ```bash
   python game_logic.py
   ```

5. Enter one letter at a time to guess the secret word.

6. Try to guess the word before the snowman melts!

7. Enter `y` to play again or another response to exit.

## Project Structure

* `game_logic.py` — Contains the game logic, input validation, and replay option.
* `ascii_art.py` — Contains the ASCII art for the snowman's melting stages.
* `.gitignore` — Prevents Python cache files from being tracked by Git.
